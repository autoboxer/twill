# Twill documentation

For installation, development, and build commands, see the [main README](../README.md).
For concise instructions about current controls, open **Using Twill** inside the
app. Its topics and examples are bundled locally and do not need a connection.

- Read [Studying effectively](studying-effectively.md) to choose activities for
  your goal, address learning difficulties, and prepare accurate content.
- Read [Research and design rationale](research.md) to understand the evidence,
  its limitations, and how it informs current and planned features.
- Read [CSS snippets](css-snippets.md) to customize appearance and recover from
  a snippet that makes the app difficult to use.

## Keeping documentation useful

Describe how available features work and label planned features clearly. Update
the relevant instructions in the same PR as a behavior change. Give each topic
one main home and link to it from other documents.

The short help shown in the app is written in [guide topics](../src/guide/topics.js).
The longer articles here provide background and detailed examples. They are not
loaded into the app. Distinguish research findings, guidance from experienced
practitioners, and decisions made for Twill.
